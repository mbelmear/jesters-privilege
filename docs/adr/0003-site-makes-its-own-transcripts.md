# The site makes its own Transcripts, kept on a `transcripts` branch

The spec first had Transcripts come from Spreaker, but Spreaker makes none: it only links a transcript made elsewhere, which would mean someone requesting one by hand for every Episode. So when the feed links no WebVTT Transcript, a workflow transcribes the Episode once with Whisper (whisper.cpp) on GitHub's runners, free for this public repo, and the host's Transcript still wins when there is one. We rejected a paid transcription API (faster and a little more accurate, but an account, a key, a bill, and a 25 MB upload limit that Episode 1 already exceeds). Finished Transcripts live on a `transcripts` branch that only the workflow writes to, because `main` accepts changes only through reviewed pull requests, which would put a human back in the weekly loop; we rejected a Cloudflare R2 bucket as another service and key to look after. Each Episode is transcribed once, so a hand fix to its file sticks.
